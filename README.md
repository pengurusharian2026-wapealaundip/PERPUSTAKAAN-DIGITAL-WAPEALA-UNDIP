# Perpustakaan Digital WAPEALA UNDIP

Fondasi frontend awal untuk website perpustakaan digital WAPEALA UNDIP.

## Isi folder
- `index.html` — struktur halaman utama
- `style.css` — desain responsif dan identitas visual
- `script.js` — interaksi pencarian, kategori, navigasi, dan dialog pengunjung
- `assets/logo-wapeala.png` — logo organisasi

## Identitas visual
Warna diambil dari logo WAPEALA:
- Merah: `#DE0B06`
- Biru: `#00519C`
- Hijau: `#006931`
- Putih: `#FFFFFF`
- Abu gelap: `#343439`

Font mengikuti panduan yang dikirim: Anton untuk judul/display dan Open Sans untuk teks utama.

## Cara melihat secara lokal
Buka `index.html` menggunakan browser.

## Catatan penting
Ini masih prototipe frontend. Form pengunjung hanya simulasi dan belum mengirim atau menyimpan data. Katalog yang ditampilkan juga contoh. Database, pencatatan kunjungan, akses admin, dan penyimpanan dokumen akan dibuat pada tahap backend berikutnya.

Jangan menaruh secret key, kata sandi, atau data pribadi di repository publik.
